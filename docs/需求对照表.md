> 状态图例：✅ 已实现并验证 / 🟡 已实现（演示替代，留真实接入点）/ ⏸ 挂起（等外部输入）。

| 用户注册库 | auth 注册 / 登录 / 审核（商户企业需资质） |
| 自动化服务 | Celery：气象采集、会话清理（每日 03:00）、审计日志 |
| AI 自动化服务 | `core/llm.py` 统一入口 + ai 模块（RAG / SSE 流式 / 会话） |

| 电商库存检测 | 条件更新防超卖 + Redis 预扣闸门 + 库存流水 + 低库存预警（概览页） |

## 七、验收操作索引

```bash

make e2e                                 # 并发正确性套件（tests_e2e/）

# 前端：类型检查 + 构建
```
